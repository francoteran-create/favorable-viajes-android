# VIGÍA — Samsung Galaxy S9+ (Android 10)
This is a build/installation scaffold, NOT a working surveillance app.
The WatchAlerts helper creates a silent Android notification for recording-start events.
It is not wired to a recorder yet. Smartwatch forwarding depends on the companion app and Bluetooth connection.
Android notifications cannot be guaranteed invisible on the phone while visible on a watch.
Airplane mode with Bluetooth re-enabled may work offline if the watch supports local notification mirroring.
Privacy indicators and required foreground-service notifications remain visible.
