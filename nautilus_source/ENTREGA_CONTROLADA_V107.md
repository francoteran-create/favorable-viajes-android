# NAUTILUS PRESENTISMO — LISTA DE ENTREGA CONTROLADA (V107)

Estado: compilación debug y release verificada por GitHub Actions. No equivale a prueba funcional en Android.
Rama: nautilus-presentismo.

## Antes de distribuir
1. NO entregar el archivo PEM del DESARROLLADOR, códigos privados ni claves de firma a los administradores.
2. La APK de prueba NO cuenta con garantía de firma persistente. Para publicar una MASTER actualizable se necesita configurar un keystore estable en secreto de GitHub y conservar un respaldo privado de él.
3. Verificar si existe otra instalación en el teléfono; una firma diferente puede impedir actualizar sin desinstalar y borrar datos.
4. Resguardar los dos Excel originales y cualquier dato o PDF de la aplicación antes de reinstalar.
5. Probar en un teléfono Android real: alta de PIN para David, Enzo, Alejandro y Mario; ingreso y cambio de usuario; importación de ambos Excel; jornadas y totales; PDF; bloqueo al vencer licencia; activación con código del mismo día; retorno al panel DESARROLLADOR.
6. La protección de licencias es offline: una reinstalación con borrado de datos puede reiniciar el período inicial. No prometer una limitación invulnerable a copias ni activación única universal sin servidor.
7. La cuenta DESARROLLADOR tiene permisos especiales y no debe compartirse. Solo el propietario debe tener la clave privada correspondiente a la clave pública integrada.
8. Hasta completar estos pasos, distribuir exclusivamente para PRUEBA PILOTO y nunca como MASTER FINAL.

## Prueba piloto
- Conservar una copia de los Excel originales.
- Instalar en un teléfono de prueba sin datos de producción.
- Verificar el ciclo completo de un mes y comparación contra cálculos manuales.
- No actualizar por encima de instalaciones con datos críticos hasta contar con firma estable y prueba de migración.

## Criterio de cierre
La entrega definitiva requiere instalación/actualización comprobadas, firma persistente, licencia funcional, cuatro cuentas administrativas, exportación PDF y controles de datos verificados.
